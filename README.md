# Bank of Dad social graphics
Public PNG assets for Buffer / Instagram / Facebook scheduling. Direct links via jsDelivr.

## Short-form videos (`video/`)

9–13 second vertical (1080x1920) app-demo videos for Instagram Reels, TikTok and YouTube Shorts, generated by
`content/video/` in the bank-of-dad repo. `video/manifest.json` and `video/schedule.csv` list each video's posting
slot (US Central), hook, caption and direct jsDelivr URL.

- Instagram: post every video as a **trial reel**.
- TikTok: one a day, the `tiktok: post` slot.
- Bio link: `https://bankofdad.io/?utm_source=<platform>&utm_medium=social&utm_campaign=shortform`
